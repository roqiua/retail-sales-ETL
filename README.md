# Retail Data ETL Project

## 📌 Overview

An **ETL project** built using **SQL Server Integration Services (SSIS)** to extract, transform, clean, and load retail data into a **SQL Server Data Warehouse**.

## 📊 Dataset

The project uses the **Retail Data** dataset from Kaggle:

[Retail Data — Kaggle](https://www.kaggle.com/datasets/hyerdrac/retail-data)

## 🛠️ Tools

* SQL Server
* SSIS
* Visual Studio
* SQL Server Management Studio (SSMS)
* SQL

## 🔄 ETL Process

```text
Kaggle Dataset
      ↓
Extract
      ↓
Transform & Clean
      ↓
Staging Tables
      ↓
Dimension & Fact Tables
      ↓
Data Warehouse
```

## 🔧 Main SSIS Components

* Flat File Source
* Data Conversion
* Derived Column
* Conditional Split
* Lookup
* Merge Join
* OLE DB Destination

## 🎯 Objective

Build a complete ETL pipeline and Data Warehouse for analyzing retail data.
